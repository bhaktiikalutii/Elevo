# ELEVO – AI Interview Agent

An intelligent AI-powered interview agent built for the **ABTalks Vibe Code Hackathon**.

ELEVO conducts personalized technical interviews based on a candidate's learning journey through the ABTalks AI Cohort. Instead of asking static questions, it adapts to the candidate's strengths, weaknesses, completed topics, and previous responses to simulate a realistic technical interview experience.

---

## 🚀 Features

- 🧠 Personalized interview generation based on candidate progress
- 📚 Curriculum-aware questioning across multiple AI topics
- 🔄 Dynamic follow-up questions based on previous answers
- 💬 Multi-turn conversational interview
- 📊 Structured evaluation and scoring
- 📝 Detailed feedback with strengths, weaknesses, and recommendations
- 🎯 Covers multiple curriculum modules with adaptive difficulty

### Problem Statement

Build an AI Interview Agent capable of conducting adaptive technical interviews based on a learner's progress through a 31-day AI Engineering Cohort.

The system should:
- Conduct realistic technical interviews
- Adapt questions based on candidate responses
- Maintain conversation context
- Evaluate performance
- Generate actionable feedback
